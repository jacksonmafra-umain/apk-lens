# A compact public-suffix list.

# "One label before the dot" is wrong: `example.co.uk` and `example.com` are
# both single registrations, and `s3.amazonaws.com` is not. Grouping hosts by
# registrable domain is what turns 991 hostnames into 445 organisations, so the
# reduction has to know where a registration actually starts.
#
# This is a trimmed list — the suffixes that appear in mobile app traffic — kept
# in the repository so the tool never makes a network call to classify a name.
# An unknown suffix falls back to "last two labels", which is right far more
# often than it is wrong.
#
# Format: one suffix per line, longest match wins. Lines starting with # are
# comments.
